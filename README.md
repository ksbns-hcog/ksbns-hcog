## Editing this site

This is plain HTML/CSS — no build step. To update content, ask Claude Code
to edit `index.html` (text, dates, links) or `style.css` (appearance), then
commit and push:

```
git add -A
git commit -m "update: ..."
git push
```

Changes appear on the live site within a minute or two of pushing.

## Structure

- `index.html` — all page content
- `style.css` — styling
- `images/` — photos for the gallery section
